# 而家路面咩情況？What Does the Road Look Like?

A simple, real-time Hong Kong traffic camera viewer that lets you check current road conditions across Hong Kong with just a few clicks.

## Features

- **Live Traffic Cameras** — View the latest images from traffic cameras across Hong Kong.
- **District & Region Selection** — Filter cameras by district and region to quickly find the roads you want to check.
- **Automatic Refresh** — Camera images are refreshed automatically to provide up-to-date road conditions.
- **Bilingual Interface** — Switch between Traditional Chinese, Simplified Chinese, and English.
- **Responsive Design** — A clean, mobile-friendly interface that works on both desktop and mobile devices

## How to Use

1. Open the web app in your browser.
2. Select a district and region using the dropdown menus.
3. Choose a traffic camera from the available locations.
4. View the latest camera image to check the road conditions.

## Data Source

Traffic camera images are provided by the **Hong Kong Transport Department** through the Hong Kong Government's [DATA.GOV.HK](https://data.gov.hk/) open data platform.

- **Traffic Camera Image API:** https://data.gov.hk/en-data/dataset/hk-td-tis_2-traffic-snapshot-images

Camera images are periodically updated by the data provider. Actual image availability and refresh intervals depend on the source.
